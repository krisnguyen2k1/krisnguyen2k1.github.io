I

How I think about the work

Three convictions that decide what I do before anyone asks me for a course.

01 / Diagnose

Training is the last resort, not the first answer.

When a department head says “my team needs communication training”, the real cause is usually an unclear process, a weak manager, or a reward that points the wrong way. Saying that out loud is what earns trust.

02 / Build

A workshop is an event. A capability engine is a system.

Anyone can run a good session. The work that compounds is the onboarding journey, the manager pathway, the microlearning that lives inside the tool people already use — things that keep running when I am not in the room.

03 / Prove

If finance cannot read the impact, the budget disappears.

Completion rate is the least interesting number I track. Measurement gets designed in on day one — retention, time to productivity, guest scores — because retrofitting it later never works.

# Phase 0 - Forensic audit

Audit scope: the live portfolio, the main branch of `krisnguyen2k1/krisnguyen2k1.github.io`, Attachment A, the supplied CV, the LinkedIn experience screenshot, the CDT certificate, two work photographs, the Obstacle Challenge HTML artifact, the Krishnamurti site, and the Tri Thuc Books store.

## Strategic problem

Kris cannot yet win an enterprise L&D shortlist by claiming management tenure. The portfolio must make a different case: an early-career practitioner has already built unusually visible learning systems, documentation, digital products and operating infrastructure. The site should prove readiness for broader L&D Specialist scope without presenting ambition as experience.

## Verdict

### What is genuinely strong and must be protected

The sentence `I turn learning operations into systems people can use and leaders can trust` is the right strategic centre. It describes a function-level mindset without pretending that Kris has held a function-lead title.

There is also real evidence behind that claim. The operating manual suggests documentation discipline. The role mapping work suggests data judgement. Culture Week demonstrates experience design, and the supplied Obstacle Challenge is far stronger than the current sentence `game design` implies. It is a working interactive product with a question flow, timer, scoring and team experience. The CDT certificate dated 26 June 2026 proves completed professional development. The supplied photographs can support facilitation credibility once publication rights and captions are confirmed.

The digital work is another defensible advantage. The Krishnamurti project is not merely a personal essay. It contains 37 chapters, a research layer, timeline, people index and explicit sourcing method. It proves independent research, information architecture, editorial judgement and the ability to ship a deep web product. Few early-career L&D candidates can show that combination.

The current site also has good foundations worth keeping: accurate restraint around confidential property data, a skip link, semantic landmarks, a single `h1`, structured data and reduced-motion handling.

### What is actively costing interviews

The false employment gap is the most urgent credibility problem. The current Story section shows Dong A ending in 2023 and Westin beginning in 2026, while the supplied LinkedIn history shows continuous roles from Dec 2023 onward. A recruiter who notices the mismatch may question the rest of the portfolio.

The Roadmap section is the second major loss. It asks a recruiter to evaluate a future Manager instead of a current Specialist candidate. It advertises missing capabilities such as budgets, team leadership and enterprise measurement before the evidence section has earned confidence.

The Evidence section names outputs but does not let a reader inspect the work. A 150-page manual may represent excellent system design or unnecessary documentation. Without a sample, context or effect, the recruiter cannot tell. The same problem affects every number. The site has claims, but no case-study proof chain.

The first viewport looks dramatic but spends too much space on the candidate's name and future title. It delays the evidence. The dark technology aesthetic also conflicts with the warmer, more credible editorial system specified in Attachment A.

Finally, the most personal material is overexposed. GPA 2.76, the large reading and film archive, the development roadmap and a personal email handle collectively make the site feel more like a thoughtful early-career profile than an application-grade enterprise portfolio.

### What is missing entirely

- Three inspectable case studies with context, decisions, artifacts, outcomes and self-critique.
- A clean downloadable CV. The supplied PDF is not publishable yet because it still contains placeholders and conflicts with the website on education status and employment dates.
- Artifact previews: manual pages, role maps, calendars, dashboards, the Obstacle Challenge and programme documentation.
- A verified measurement layer. No outcome data has yet been provided.
- A curated hierarchy for the eight digital projects.
- A precise, continuous employment timeline.
- A proof-backed explanation of bilingual capability.
- A reusable content structure for adding work without editing one large HTML file.

## Decision on future artifact uploads

A public click-to-upload control cannot persist files on a static GitHub Pages site by itself. A visible file input would only select a file on the current device. It would not publish that file for recruiters. Persistent uploads require authentication, storage and a backend or CMS, which adds security and maintenance that the current portfolio does not need.

The recommended solution is to build reusable `Artifact slot` components with clear placeholders and captions. New images can later be added through the repository or a lightweight content workflow. This keeps the public portfolio static, fast and secure while making future additions straightforward. A CMS can be reconsidered only if Kris will update evidence frequently enough to justify it.

# Phase 3 - Complete website copy

## Copy standard

- Primary language: British English.
- Headings, labels and buttons: sentence case.
- Date ranges: standard hyphens only.
- No em dash or en dash in new site copy.
- No invented outcomes, testimonials, clients or responsibilities.
- Any unresolved content is marked `[NEEDS INPUT: ...]` and must be hidden from the published build until resolved.

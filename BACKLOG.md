# Prioritised portfolio backlog

This backlog contains recommended work that is not part of the current public release. Evidence and confidentiality tasks take priority over visual additions.

## P0 - Required before merging the rebuild

- Run visual QA in a real browser at 390px, 768px, 1024px and 1440px.
- Complete the keyboard walkthrough in Chrome or Edge and one second browser.
- Run Lighthouse on Home, Work, About, Digital work and Reading.
- Measure coral coverage in each home-page viewport and confirm it remains below 10%.
- Review a grayscale capture of the home page.
- Confirm GitHub Pages is configured to use GitHub Actions.
- Confirm no CV, internal Obstacle Challenge file or workplace photograph appears in the pull request.

## P1 - Highest portfolio-value work

- Close the evidence gate for the L&D operating manual with a redacted contents page and workflow spread.
- Close the evidence gate for role-based learning paths with a redacted map and one anonymised decision example.
- Close the Culture Week contribution and live-use evidence gate.
- Prepare a publication-safe CV and add the download link.
- Verify every external digital-project URL immediately before release.

## P2 - Strengthen credibility after launch

- Collect adoption evidence for the manual and role-mapping work.
- Add one measured learning or behaviour check to the next Culture Week iteration.
- Add a confirmed writing index and open the Writing route to search engines.
- Add one short methodology note explaining how project sources are selected and checked.
- Add a current professional credential section after education and certification status is verified.

## P3 - Optional expansion

- Decide whether a Vietnamese version materially helps the target hiring audience.
- Add a print stylesheet for case-study review.
- Add privacy-respecting analytics only if a real decision will be made from the data.
- Audit and modernise the preserved legacy routes separately.
- Add automated external-link checking with conservative retry and timeout rules.

## Explicitly not recommended now

- A public artifact-upload form.
- More animation or decorative illustration.
- A dark-mode toggle.
- Generic testimonials without traceable permission.
- Placeholder metrics or estimated business outcomes.
- Publishing internal brand files only to make case pages look complete.
